# Лабораторная работа №1 по ООП

[![Release](https://img.shields.io/github/v/release/Vareshka86/Lab1_OOP_try1)](https://github.com/Vareshka86/Lab1_OOP_try1/releases)

Ссылки, указатели и динамическая память на C++14 — консольная программа по лабораторной работе №1.

Программа выполняет задания [лабораторной работы №1](https://aleksandr-003.github.io/labs/OOP_z/Labs1_1.html) курса «Объектно-ориентированное программирование и проектирование» (А. Д. Смородинов). Работа сдаётся по частям: каждое задание выходит отдельной версией. Сейчас выполнено задание 1 из 4 — статический массив, который передаётся в функции по ссылке.

## Требования

- Компилятор g++ с поддержкой C++14. Проверено на g++ 16.2.0 (MinGW-w64, Windows 10).
- Doxygen — для сборки документации, необязательно. Проверено на версии 1.18.0.

## Установка

```bash
git clone https://github.com/Vareshka86/Lab1_OOP_try1.git
cd Lab1_OOP_try1
```

Без git: откройте [Releases](https://github.com/Vareshka86/Lab1_OOP_try1/releases), скачайте архив **Source code (zip)** нужной версии и распакуйте его. Обновить клонированный репозиторий: `git pull`.

## Сборка и запуск

**Windows** (cmd или PowerShell):

```console
$ .\build.bat
Сборка успешна: build\lab1.exe
```

```powershell
.\build\lab1.exe
```

Что произошло:

- `build.bat` собрал программу из файлов папки `src` с флагами `-std=c++14 -Wall -Wextra -pedantic -static`; предупреждений компилятора нет.
- Флаг `-static` встраивает библиотеки MinGW в `lab1.exe`, поэтому программа запускается и на компьютере без компилятора.

**Linux и macOS** — на этих системах сборка не проверялась:

```bash
g++ -std=c++14 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o lab1
./lab1
```

## Как это работает

Массив из 10 чисел передаётся в функции как ссылка на массив `int (&arr)[10]`: функции работают с исходным массивом, а компилятор знает его размер. Поэтому `printArray` перебирает элементы циклом range-based for с `const auto&`, а `multiplyByTwo` — с неконстантной ссылкой `int&`, через которую меняются сами элементы. `swapElements` проверяет индексы и меняет элементы через `swapValues(int&, int&)`. Ввод проверяется: программа отклоняет буквы, дробные числа и переполнение `int`, а умножение не выходит за пределы `int`.

Подробное описание решения — на странице [«Задание №1»](pages/task1.md).
