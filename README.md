# Лабораторная работа №1 по ООП

Дисциплина: «Объектно-ориентированное программирование и проектирование».
Тема: основы C++ — ссылки, указатели, динамическая память, функции.

Задание: <https://aleksandr-003.github.io/labs/OOP_z/Labs1_1.html>

Работа выполняется **поэтапно**: каждое задание — отдельная версия программы,
сохранённая в git с меткой (тегом). Что сделано в каждой версии — см. [CHANGELOG.md](CHANGELOG.md).

## Структура проекта

```
Lab1_OOP_try1/
├── include/          заголовочные файлы (объявления + документация Doxygen)
│   ├── input.h       безопасный ввод чисел с клавиатуры
│   └── task1.h       Задание №1
├── src/              файлы реализации
│   ├── main.cpp      главное меню программы
│   ├── input.cpp
│   └── task1.cpp
├── build.bat         сборка в Windows
├── Doxyfile          настройки Doxygen
├── CHANGELOG.md      история версий
└── README.md         этот файл
```

## Сборка и запуск

Нужен компилятор с поддержкой C++17 (g++ 7 и новее).

**Windows** (MinGW-w64):

```
build.bat
build\lab1.exe
```

**Linux / macOS**:

```
g++ -std=c++17 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o lab1
./lab1
```

## Документация

Код документирован комментариями в формате Doxygen
(`@brief`, `@param`, `@return`, `@details`, `@warning`, `@note`).
Сборка HTML-документации:

```
doxygen Doxyfile
```

Результат — `docs/html/index.html`.

## Работа с git

- `main` — основная ветка, в ней только законченные версии;
- для каждого задания создаётся отдельная ветка от последней версии
  (`task1`, `task2`, …), в ней делаются коммиты по ходу работы;
- готовая ветка сливается в `main`, и на результат ставится метка версии (`v0.1`, `v0.2`, …).
