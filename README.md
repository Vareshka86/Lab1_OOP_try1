# Лабораторная работа №1 по ООП

[![Release](https://img.shields.io/github/v/release/Vareshka86/Lab1_OOP_try1)](https://github.com/Vareshka86/Lab1_OOP_try1/releases)

Ссылки, указатели и динамическая память на C++14 — консольная программа по лабораторной работе №1.

Программа выполняет задания [лабораторной работы №1](https://aleksandr-003.github.io/labs/OOP_z/Labs1_1.html) курса «Объектно-ориентированное программирование и проектирование» (А. Д. Смородинов). Работа сдавалась по частям: каждое задание выходило отдельной версией. Выполнены все четыре задания: статический массив, который передаётся в функции по ссылке, динамический массив с `new`/`delete`, структура `SafeArray` с безопасным доступом к элементам и изменением размера и двумерный динамический массив для учёта оценок студентов.

```console

...
```

## Сборка и запуск

**Windows** (cmd или PowerShell):

```console
$ .\build.bat
Сборка успешна: build\lab1.exe
```

```powershell
.\build\lab1.exe
```

Что произошло:

- `build.bat` собрал программу из файлов папки `src` с флагами `-std=c++14 -Wall -Wextra -pedantic -static`; предупреждений компилятора нет.
- Флаг `-static` встраивает библиотеки MinGW в `lab1.exe`, поэтому программа запускается и на компьютере без компилятора.

**Linux и macOS** — на этих системах сборка не проверялась:

```bash
g++ -std=c++14 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o lab1
./lab1
```

## Как это работает

**Задание 1.** Массив из 10 чисел передаётся в функции как ссылка на массив `IntArray& arr`, где `using IntArray = int[10];` (та же ссылка, что `int (&arr)[10]`): функции работают с исходным массивом, а компилятор знает его размер. Поэтому `printArray` перебирает элементы циклом range-based for с `const auto&`, а `multiplyByTwo` — с неконстантной ссылкой `int&`, через которую меняются сами элементы. `swapElements` проверяет индексы и меняет элементы через `swapValues(int&, int&)`.

**Задание 2.** Размер N вводит пользователь, поэтому память выделяется во время работы: `new int[N]{}`. Функция `process` получает указатель по ссылке `int*&`: она создаёт новый массив из элементов до первого отрицательного, освобождает старый через `delete[]` и записывает новый адрес прямо в указатель вызывающей стороны. В конце `freeArray` освобождает память и обнуляет указатель, а вывод по обнулённому указателю проверяет `nullptr` и к памяти не обращается.

**Задание 3.** Структура `SafeArray` хранит указатель на динамический массив вместе с его размером, поэтому функция доступа `getElement` всегда знает границы. Она возвращает ссылку `int&` на элемент, и её вызов можно ставить слева от знака равенства: `getElement(myArr, 2) = 999`. При неверном индексе функция выводит ошибку и возвращает ссылку на статическую локальную переменную-заглушку, поэтому запись не портит массив, а программа не падает. `printSafe` получает массив по константной ссылке и читает элементы через указатель на константу. `reSizeArray` меняет размер с N на M: выделяет новый массив `new int[M]{}`, копирует общие элементы, при уменьшении выводит удалённые, а старый массив освобождает.

**Задание 4.** Оценки хранятся в двумерном динамическом массиве: строка — студент, столбец — номер оценки. `allocateMatrix` выделяет массив указателей `new int*[rows]{}`, а затем каждую строку `new int[cols]{}`, поэтому матрица имеет тип «указатель на указатель» `int**`. У `printMatrix` два параметра со значениями по умолчанию (`showBorders = true`, `title = "Matrix"`), и функция вызывается тремя способами: без них, только с заголовком и со всеми параметрами. `freeMatrix` освобождает память в обратном порядке: сначала строки, затем массив указателей.

Ввод во всех заданиях проверяется: программа отклоняет буквы, дробные числа и числа вне допустимого диапазона. Подробное описание решений — на страницах [«Задание №1»](pages/task1.md), [«Задание №2»](pages/task2.md), [«Задание №3»](pages/task3.md) и [«Задание №4»](pages/task4.md).
