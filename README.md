# Лабораторная работа №1 по ООП

[![Release](https://img.shields.io/github/v/release/Vareshka86/Lab1_OOP_try1)](https://github.com/Vareshka86/Lab1_OOP_try1/releases)

Ссылки, указатели и динамическая память на C++14 — консольная программа по лабораторной работе №1.

Программа выполняет задания [лабораторной работы №1](https://aleksandr-003.github.io/labs/OOP_z/Labs1_1.html) курса «Объектно-ориентированное программирование и проектирование» (А. Д. Смородинов). Работа сдаётся по частям: каждое задание выходит отдельной версией. Сейчас выполнены задания 1 и 2 и первая часть задания 3: статический массив, который передаётся в функции по ссылке, динамический массив с `new`/`delete` и структура `SafeArray` с безопасным доступом к элементам.

## Сборка и запуск

**Windows** (cmd или PowerShell):

```console
$ .\build.bat
Сборка успешна: build\lab1.exe
```

```powershell
.\build\lab1.exe
```

Что произошло:

- `build.bat` собрал программу из файлов папки `src` с флагами `-std=c++14 -Wall -Wextra -pedantic -static`; предупреждений компилятора нет.
- Флаг `-static` встраивает библиотеки MinGW в `lab1.exe`, поэтому программа запускается и на компьютере без компилятора.

**Linux и macOS** — на этих системах сборка не проверялась:

```bash
g++ -std=c++14 -Wall -Wextra -pedantic -Iinclude src/*.cpp -o lab1
./lab1
```

## Как это работает

**Задание 1.** Массив из 10 чисел передаётся в функции как ссылка на массив `int (&arr)[10]`: функции работают с исходным массивом, а компилятор знает его размер. Поэтому `printArray` перебирает элементы циклом range-based for с `const auto&`, а `multiplyByTwo` — с неконстантной ссылкой `int&`, через которую меняются сами элементы. `swapElements` проверяет индексы и меняет элементы через `swapValues(int&, int&)`.

**Задание 2.** Размер N вводит пользователь, поэтому память выделяется во время работы: `new int[N]{}`. Функция `process` получает указатель по ссылке `int*&`: она создаёт новый массив из элементов до первого отрицательного, освобождает старый через `delete[]` и записывает новый адрес прямо в указатель вызывающей стороны. В конце `freeArray` освобождает память и обнуляет указатель, а вывод по обнулённому указателю проверяет `nullptr` и к памяти не обращается.

**Задание 3, часть 1.** Структура `SafeArray` хранит указатель на динамический массив вместе с его размером, поэтому функция доступа `getElement` всегда знает границы. Она возвращает ссылку `int&` на элемент, и её вызов можно ставить слева от знака равенства: `getElement(myArr, 2) = 999`. При неверном индексе функция выводит ошибку и возвращает ссылку на статическую локальную переменную-заглушку, поэтому запись не портит массив, а программа не падает. `printSafe` получает массив по константной ссылке и читает элементы через указатель на константу.

Ввод во всех заданиях проверяется: программа отклоняет буквы, дробные числа и числа вне допустимого диапазона. Подробное описание решений — на страницах [«Задание №1»](pages/task1.md), [«Задание №2»](pages/task2.md) и [«Задание №3»](pages/task3.md).
