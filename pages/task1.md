## Условие задания

Написать программу, которая создаёт статический массив из 10 целых чисел.
Реализовать и вызвать следующие функции (для передачи аргументов использовать **ссылки**):

- `fillArray(…)` — заполняет массив случайными числами (или через `std::cin`); использовать ссылку на массив;
- `printArray(…)` — выводит массив на экран, используя range-based for цикл и `auto`;
- `swapElements(…)` — меняет местами два элемента массива по их индексам, передача аргументов по ссылке;
- `multiplyByTwo(…)` — умножает каждый элемент массива на 2, используя range-based for с неконстантной ссылкой (`int& x`).

## Как решено

Массив создаётся в функции runTask1(): `int numbers[ARRAY_SIZE]{};` — статический массив
из ARRAY_SIZE = 10 элементов, фигурные скобки `{}` обнуляют все элементы.
Дальше пользователь выбирает действия в меню, и вызываются функции задания:

| Функция | Что делает | Как получает массив | Что демонстрирует |
|---------|------------|---------------------|-------------------|
| fillArray() | заполняет массив случайными числами или с клавиатуры | `int (&arr)[10]` | ссылка на массив; параметр по умолчанию; range-based for с `int&` |
| printArray() | выводит индексы и значения | `const int (&arr)[10]` | range-based for с `const auto&` |
| swapElements() | меняет местами `arr[i]` и `arr[j]` | `int (&arr)[10]` | передача элементов по ссылке в swapValues() |
| multiplyByTwo() | умножает каждый элемент на 2 | `int (&arr)[10]` | range-based for с неконстантной ссылкой `int& x` |
| runTask1() | меню задания | — | создаёт массив и вызывает все функции |

Код задания: task1.h (объявления и документация), task1.cpp (реализация).
Безопасный ввод чисел: input.h, input.cpp.

## Ссылка на массив вместо указателя

В языке Си массив, переданный в функцию, превращается в указатель на первый
элемент, и информация о размере теряется. В C++ можно передать **ссылку на массив**:

```cpp
void printC(int arr[]);                  // Си: на самом деле int* arr, размер неизвестен
void printArray(const int (&arr)[10]);   // C++: ссылка на массив ровно из 10 элементов
```

Что это даёт:
- массив **не копируется** — функция работает с исходным массивом;
- компилятор знает размер, поэтому внутри функции работает range-based for;
- передать массив другого размера нельзя — будет **ошибка компиляции**;
- ссылка не может быть «пустой» (как `nullptr` у указателя), проверять её не нужно.

Скобки в записи `int (&arr)[10]` обязательны: без них `int &arr[10]` означало бы
«массив из 10 ссылок», а массивы ссылок в C++ запрещены.

## Range-based for: копия, ссылка и константная ссылка

```cpp
for (int x : arr)        { x *= 2; }   // x - КОПИЯ элемента: массив НЕ изменится
for (int& x : arr)       { x *= 2; }   // x - ССЫЛКА на элемент: массив изменится (multiplyByTwo)
for (const auto& x : arr) { std::cout << x; } // только чтение без копирования (printArray)
```

- `auto` — тип переменной компилятор выводит сам (здесь `int`);
- `&` — переменная цикла становится другим именем элемента массива, копии нет;
- `const` — через переменную нельзя изменить элемент (защита от случайной ошибки).

## Обмен элементов через ссылки

```cpp
void swapValues(int& a, int& b)          // a и b - другие имена переменных вызывающей стороны
{
    const int temp = a;
    a = b;
    b = temp;
}

swapValues(arr[first], arr[second]);     // внутри swapElements(): меняются сами элементы массива
```

Для сравнения, в Си то же самое пришлось бы делать через указатели:
`swapC(&arr[first], &arr[second])` и разыменование `*a` внутри функции.
Со ссылками синтаксис проще, а передать «пустой» адрес невозможно.

## Защита от ошибок

- **Некорректный ввод.** Функции readInt() и readIntInRange() читают строку целиком и
  принимают её, только если в ней ровно одно целое число из нужного диапазона.
  Строки `abc`, `12abc`, `3.5`, `99999999999` отклоняются, и ввод повторяется.
- **Неверные индексы.** swapElements() проверяет, что индексы лежат в диапазоне 0–9,
  и отдельно сообщает, если индексы совпадают.
- **Переполнение int.** multiplyByTwo() сначала проверяет, что каждый элемент после
  умножения на 2 поместится в `int` (иначе — неопределённое поведение), и только потом умножает.
- **Конец ввода.** Если поток ввода закончился (Ctrl+Z), программа не зацикливается,
  а завершается с понятным сообщением об ошибке.
