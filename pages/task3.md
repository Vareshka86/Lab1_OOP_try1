# Задание №3. Безопасный массив SafeArray {#task3}

[TOC]

## Условие задания

Безопасный массив:

1. Объявить структуру:
   ```cpp
   struct SafeArray {
       int* data;
       int size;
   };
   ```
2. Написать функцию `SafeArray createArray(int size)`, которая выделяет память и возвращает структуру по значению.
3. Написать функцию доступа к элементам `int& getElement(SafeArray& arr, int index)`:
   - проверить, не вышел ли `index` за границы `arr.size`; если вышел — вывести ошибку и вернуть ссылку
     на статическую локальную переменную-заглушку (чтобы программа не упала, но изменение не сломало
     основной массив);
   - если индекс корректный — вернуть ссылку на `arr.data[index]`.
4. Показать, что функцию можно использовать слева от знака равенства: `getElement(myArr, 2) = 999;`.
5. Написать функцию `void printSafe(const SafeArray& arr)`, которая выводит массив, используя `const`
   (так как печать не требует изменения данных).
6. Написать функцию `reSizeArray(int N, int M)`, которая изменяет размер массива с N элементов на M:
   - если элементов стало меньше — на экран выводятся удалённые элементы;
   - если элементов стало больше — новые элементы равны 0 по умолчанию.

Задание выполнено в две части: **пункты 1–5 — версия v0.3, пункт 6 — версия v0.4.**

## Как решено

Задание показывает runTask3(): спрашивает размер (от 3 до 15 — нужен элемент с индексом 2), создаёт
массив, заполняет его, выполняет запись из пункта 4 и обращение по неверному индексу, а затем даёт из
меню читать и записывать элементы по любому индексу и менять размер массива.

| Функция | Что делает | Что демонстрирует |
|---------|------------|-------------------|
| createArray() | выделяет `new int[size]{}` и возвращает структуру `{указатель, размер}` | возврат структуры по значению |
| getElement() | возвращает ссылку на элемент; при неверном индексе — ошибку и ссылку на заглушку | возврат ссылки из функции, вызов слева от `=`, статическая локальная переменная |
| printSafe() | выводит индексы и значения | константная ссылка, указатель на константу |
| reSizeArray() | меняет размер с N на M: новый массив, копирование, вывод удалённых элементов, `delete[]` старого | перевыделение динамической памяти |
| freeSafeArray() | `delete[]`, затем `data = nullptr`, `size = 0` | освобождение памяти без «болтающегося» указателя |
| runTask3() | демонстрация пунктов 1–6 и меню | — |

Код задания: task3.h (объявления и документация), task3.cpp (реализация).

## Структура вместо пары «указатель + размер»

В Задании №2 функции получали массив двумя параметрами: `int* arr` и `int size`. Структура
SafeArray хранит их вместе, поэтому функции получают один параметр и всегда знают размер — именно
это позволяет getElement() проверять границы, а reSizeArray() — менять размер.

createArray() возвращает структуру **по значению**: вызывающая сторона получает копию структуры, то
есть копию указателя и размера. Сами элементы при этом не копируются — они остаются в динамической
памяти, и на них смотрит скопированный указатель.

## Возврат ссылки и вызов слева от знака равенства

```cpp
int& getElement(SafeArray& arr, int index);

getElement(myArr, 2) = 999;          // запись: ссылка - это сам элемент arr.data[2]
int value = getElement(myArr, 1);    // чтение: значение элемента копируется в value
```

Функция возвращает не число, а **ссылку** на элемент — другое имя самого `arr.data[index]`.
Поэтому присваивание этой ссылке записывает значение прямо в массив.

## Статическая заглушка

Если индекс выходит за границы, вернуть ссылку на элемент нельзя: такого элемента нет. Возвращать
ссылку на обычную локальную переменную тоже нельзя — она уничтожается при выходе из функции, и
ссылка «повиснет». Поэтому используется **статическая локальная переменная**:

```cpp
static int dummy = 0;   // создаётся один раз и живёт до конца программы
...
dummy = 0;              // при каждой выдаче обнуляется
return dummy;           // запись в заглушку не затрагивает основной массив
```

Запись `getElement(myArr, 5) = 555` при массиве из 5 элементов изменяет заглушку, а массив остаётся
прежним. Чтение по неверному индексу всегда даёт 0.

## const в printSafe

`const SafeArray& arr` — структура не копируется, и функция не может изменить её поля: указатель
`data` и размер `size`. Но `data` имеет тип `int*`, поэтому сами числа через него изменить было бы
можно. Чтобы печать гарантированно ничего не меняла, элементы читаются через указатель на константу:

```cpp
const int* values = arr.data;   // через values элементы можно только читать
```

## Изменение размера: reSizeArray

В условии функция записана как `reSizeArray(int N, int M)`. Чтобы она знала, какой массив менять,
первым параметром передаётся сам массив по ссылке; N и M сохраняют смысл из условия:

```cpp
void reSizeArray(SafeArray& arr, int N, int M);   // N - текущий размер, M - новый

reSizeArray(myArr, myArr.size, M);
```

Размер уже выделенного массива изменить нельзя, поэтому функция:

1. Выделяет новый массив `new int[M]{}` — фигурные скобки сразу обнуляют все элементы.
2. Копирует в него первые min(N, M) элементов старого массива.
3. Если M < N, выводит удалённые элементы (индексы M … N − 1). Если M > N, новые элементы
   (индексы N … M − 1) так и остаются равными 0.
4. Освобождает старый массив `delete[]` и записывает в структуру новый указатель и размер M.

Функция проверяет входные данные: N должен совпадать с `arr.size`, M — быть больше 0, массив —
существовать. Иначе выводится ошибка и массив не меняется; при M = N менять нечего.

## Защита от ошибок

- **Размер массива** — только целое число от 3 до 15, новый размер M — от 1 до 15 (readIntInRange()).
- **Неверный индекс** (отрицательный или не меньше `size`) — сообщение об ошибке и заглушка;
  массив не меняется, программа не падает. После уменьшения размера бывшие индексы тоже
  становятся неверными: getElement() проверяет границы по новому `size`.
- **Освобождение памяти** — reSizeArray() освобождает старый массив сразу после копирования,
  freeSafeArray() в конце обнуляет указатель и размер; после этого printSafe() и getElement() видят,
  что массива нет, и к памяти не обращаются.
- **Прерванный ввод** — runTask3() освобождает память и передаёт исключение дальше в `main`.
- **Проверка.** Отдельная тестовая программа со счётчиком `new[]`/`delete[]` (25 проверок): после
  каждого изменения размера живёт ровно один массив, при увеличении новые элементы равны 0, при
  неверных N и M массив не меняется; после freeSafeArray() утечек нет; запись по неверным индексам
  не меняет массив, все неверные индексы дают одну и ту же заглушку.

  arr[3] = 40

Действия с массивом:
  1 - вывести массив            (printSafe)
