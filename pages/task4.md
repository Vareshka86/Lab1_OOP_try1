# Задание №4. Учёт оценок студентов {#task4}

[TOC]

## Условие задания

Разработать систему для учёта оценок студентов.

1. Написать функцию выделения памяти под двумерный массив: `int** allocateMatrix(int rows, int cols);`
2. Написать функцию заполнения: `void fillMatrix(int** matrix, int rows, int cols);`
3. Написать функцию красивого вывода с параметрами по умолчанию:
   ```cpp
   void printMatrix(int** matrix, int rows, int cols, bool showBorders = true, std::string title = "Matrix");
   ```
   - если `showBorders == true`, выводить рамочку из символов `*` или `-` вокруг матрицы;
   - вызвать функцию три раза: без дополнительных параметров, только с заголовком и со всеми параметрами.
4. Написать функцию `void freeMatrix(int** matrix, int rows)`, которая корректно очищает память
   (сначала вложенные массивы, потом массив указателей).

## Как решено

Оценки хранятся в двумерном динамическом массиве: строка — студент, столбец — номер оценки. Количество
студентов и оценок (от 1 до 10) вводит пользователь, оценки — целые числа от 2 до 5.

| Функция | Что делает | Что демонстрирует |
|---------|------------|-------------------|
| allocateMatrix() | выделяет массив указателей `new int*[rows]{}` и строки `new int[cols]{}` | двумерный динамический массив, указатель на указатель `int**` |
| fillMatrix() | заполняет оценки случайно или с клавиатуры | обращение к элементу `matrix[i][j]` |
| printMatrix() | выводит таблицу с заголовком, по желанию — в рамке из `*` | параметры по умолчанию |
| freeMatrix() | освобождает строки, затем массив указателей | правильный порядок освобождения памяти |
| runTask4() | демонстрация по шагам условия и три вызова printMatrix() | — |

Код задания: task4.h (объявления и документация), task4.cpp (реализация). В программе с меню демонстрация
каждого задания вынесена в отдельную функцию: три вызова printMatrix() выполняет runTask4(), которую
вызывает `main` при выборе пункта 4.

## Двумерный динамический массив: указатель на указатель

Размеры матрицы становятся известны только во время работы программы, поэтому память выделяется в два шага:

```cpp
int** matrix = new int*[rows]{};      // 1. массив из rows указателей - по одному на строку
for (int i = 0; i < rows; ++i)
{
    matrix[i] = new int[cols]{};      // 2. каждая строка - отдельный массив из cols чисел
}
```

`matrix` указывает на массив указателей, а каждый указатель `matrix[i]` — на свою строку. Поэтому тип
матрицы — **указатель на указатель** `int**`. Запись `matrix[i][j]` читается так: `matrix[i]` — указатель
на строку i, `[j]` — элемент этой строки. Пустые фигурные скобки `{}` обнуляют выделенную память: в первом
массиве все указатели равны `nullptr`, во вторых — все оценки равны 0.

Строки лежат в памяти в разных местах, не подряд: каждая выделена своим `new`.

Если при выделении какой-то строки памяти не хватит (`new` выбросит исключение `std::bad_alloc`),
allocateMatrix() освобождает уже выделенное через freeMatrix() и передаёт исключение дальше. Это
безопасно потому, что указатели невыделенных строк остались равными `nullptr` благодаря `{}`.

## Параметры по умолчанию

Значения по умолчанию записываются **только в объявлении** функции (в task4.h); в определении (в
task4.cpp) их не повторяют — иначе компилятор выдаст ошибку:

```cpp
// task4.h
void printMatrix(int** matrix, int rows, int cols, bool showBorders = true,
                 std::string title = "Matrix");
// task4.cpp
void printMatrix(int** matrix, int rows, int cols, bool showBorders, std::string title) { ... }
```

Если аргумент не передан, компилятор подставляет значение по умолчанию. Три вызова из условия:

```cpp
printMatrix(grades, rows, cols);                              // рамка есть, заголовок "Matrix"
printMatrix(grades, rows, cols, true, "Оценки студентов");    // только свой заголовок
printMatrix(grades, rows, cols, false, "Оценки без рамки");   // все параметры заданы явно
```

Аргументы подставляются по порядку, слева направо, и пропустить параметр в середине списка нельзя.
Поэтому во втором вызове, чтобы задать только заголовок, приходится указать и `showBorders` — со
значением `true`, как по умолчанию. Параметры по умолчанию могут стоять только в конце списка.

## Рамка вокруг матрицы

Рамка рисуется символами `*`, заголовок отделяется от таблицы линией из `-`. Ширина рамки подстраивается
под самую длинную строку — таблицы или заголовка, поэтому длинный заголовок рамку не ломает.

Для выравнивания русского текста `std::setw` не подходит: в кодировке UTF-8 русская буква занимает 2 байта,
а `setw` считает байты, а не символы. Поэтому ширина строки считается отдельной функцией: она пропускает
байты продолжения символа (вида `10xxxxxx`) и считает только первые байты символов.

## Освобождение памяти: freeMatrix

```cpp
for (int i = 0; i < rows; ++i)
{
    delete[] matrix[i];   // 1. сначала каждая строка
}
delete[] matrix;          // 2. потом массив указателей
```

Порядок обратный выделению. Если сначала удалить массив указателей, адреса строк пропадут вместе с ним:
строки освободить уже не получится (утечка памяти), а чтение `matrix[i]` из освобождённой памяти —
ошибка. Для каждого `new[]` выполняется ровно один `delete[]`: всего rows + 1 раз.

freeMatrix() получает указатель **по значению** — копию. Обнулить указатель вызывающей стороны она не
может, поэтому после вызова его обнуляет runTask4(): `grades = nullptr;`.

## Защита от ошибок

- **Ввод** — количество студентов и оценок только от 1 до 10, оценка — только от 2 до 5; буквы, дробные
  числа и числа вне диапазона отклоняются (readIntInRange()).
- **Неверные размеры** — allocateMatrix() при `rows <= 0` или `cols <= 0` возвращает `nullptr` и память не
  выделяет; fillMatrix(), printMatrix() и freeMatrix() проверяют `nullptr` и к памяти не обращаются.
- **Нехватка памяти** — allocateMatrix() освобождает уже выделенные строки и передаёт исключение дальше.
- **Прерванный ввод** — runTask4() освобождает память и передаёт исключение дальше в `main`.
- **Проверка.** Отдельная тестовая программа со счётчиком `new[]`/`delete[]` (28 проверок): матрица
  rows × cols занимает rows + 1 массив, все элементы равны 0; после freeMatrix() утечек нет; при
  искусственной нехватке памяти на любой строке утечек нет; все строки рамки одной ширины, в том числе
  с заголовком длиннее таблицы; без рамки символов `*` нет; полный сценарий runTask4() и прерванный
  ввод не оставляют неосвобождённой памяти.
