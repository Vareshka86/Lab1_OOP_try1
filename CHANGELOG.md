# История версий

Здесь записано, что было сделано в каждой версии лабораторной работы.
Каждой версии в git соответствует метка (тег) с тем же именем.

## v0.3 — 2026-10-02

Выполнена часть 1 из 2 задания 3: структура `SafeArray` и безопасный доступ к элементам
(пункты 1–5 условия). Пункт 6 — изменение размера массива `reSizeArray` — войдёт в версию v0.4.

### Сделано

- Задание №3, часть 1 (`task3.h` / `task3.cpp`):
  - структура `SafeArray { int* data; int size; }`;
  - `createArray(int size)` — выделяет `new int[size]{}` и возвращает структуру по значению;
  - `getElement(SafeArray& arr, int index)` — возвращает ссылку на элемент; при выходе за
    границы выводит ошибку и возвращает ссылку на статическую локальную заглушку, поэтому
    запись `getElement(myArr, 2) = 999` работает, а неверный индекс не портит массив;
  - `printSafe(const SafeArray& arr)` — вывод через константную ссылку и указатель на константу;
  - `freeSafeArray()` — освобождение памяти и обнуление структуры;
  - `runTask3()` — демонстрация пунктов 1–5 и меню: чтение и запись элемента по любому индексу.
- Главное меню: пункт 3 запускает Задание №3 (часть 1), версия программы — v0.3.
- Страница документации `pages/task3.md`: условие, разделение задания на две части, решение,
  пример работы программы.
- README: задание 3 разделено в таблице на две части, пример вывода — работа Задания №3.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Задание №3: заполнение с клавиатуры и случайными числами, запись `getElement(myArr, 2) = 999`,
  запись и чтение по неверным индексам (5, 7, −1), запись из меню, неверный ввод размера
  (2, 16, «abc», «4.5»), прерванный ввод, вывод после освобождения памяти.
- Отдельная тестовая программа со счётчиком `new[]`/`delete[]`: утечек нет, повторное
  освобождение безопасно, неверные индексы не меняют массив и дают одну заглушку,
  `createArray(0)` память не выделяет — 14 проверок из 14.
- Задания 1 и 2 работают как раньше.
- Doxygen 1.18.0 собирает документацию без предупреждений.

### Следующая версия (v0.4)

- Задание №3, часть 2: функция `reSizeArray` — изменение размера массива с N на M элементов;
  при уменьшении выводятся удалённые элементы, при увеличении новые элементы равны 0.

## v0.2 — 2026-10-02

Выполнено задание 2 из 4: одномерный динамический массив, `new`/`delete` и ссылка на указатель.

### Сделано

- Задание №2 (`task2.h` / `task2.cpp`):
  - размер массива N вводится с клавиатуры (от 1 до 15), память выделяется через `new int[N]{}`;
  - `findFirstNegative()` — индекс первого отрицательного элемента или −1;
  - `process(int*& arr, int size)` — создаёт новый массив из элементов до первого
    отрицательного, освобождает старый через `delete[]` и меняет указатель вызывающей
    стороны (ссылка на указатель);
  - `printDynamicArray()` — вывод массива с проверкой указателя на `nullptr`;
  - `freeArray()` — `delete[]` и обнуление указателя;
  - `runTask2()` — шаги 1–5 условия; при прерванном вводе память освобождается до
    передачи исключения дальше.
- Генератор случайных чисел вынесен из Задания №1 в общий модуль `random_number.h` /
  `random_number.cpp`: он нужен обоим заданиям. Поведение Задания №1 не изменилось.
- `build.bat` собирает все файлы `src\*.cpp`, новые модули не требуют правки скрипта.
- Главное меню: пункт 2 запускает Задание №2, версия программы — v0.2.
- Страница документации `pages/task2.md`: условие, решение, объяснение `new[]`/`delete[]`,
  ссылки на указатель и обнуления указателя, пример работы программы.
- README: новое описание лабораторной работы (сделано 2026-10-02 в ветке `docs-readme`),
  в этой версии добавлены задание 2 и вывод его работы.

### Проверено

- Сборка `g++ -std=c++14 -Wall -Wextra -pedantic -static` (g++ 16.2.0) — без ошибок и предупреждений.
- Задание №2: отрицательный элемент в середине массива, отрицательных нет, отрицательный
  первый (пустой результат), случайное заполнение при N = 15, неверный ввод размера
  (0, 16, «abc», «2.5»), прерванный ввод элементов.
- Отдельная тестовая программа с подменёнными операторами `new[]` и `delete[]`
  (счётчик неосвобождённых массивов): после каждого случая утечек нет, указатель после
  `freeArray()` равен `nullptr`, повторный `freeArray()` безопасен — 15 проверок из 15.
- Задание №1 после переноса генератора случайных чисел работает как раньше.
- Doxygen 1.18.0 собирает документацию без предупреждений.

## v0.1 — 2026-10-01

**Выполнено Задание №1 (из четырёх): статический массив из 10 целых чисел и передача аргументов по ссылке.**

### Сделано

- Создана структура проекта: папки `include/`, `src/`, `pages/`, файлы `README.md`,
  `.gitignore`, `.gitattributes`.
- Скрипт сборки `build.bat`: компиляция `g++ -std=c++17 -Wall -Wextra -pedantic -static`.
  Флаг `-static` делает `lab1.exe` самодостаточным — он запускается и без установленного MinGW.
- Настроен Doxygen (`Doxyfile`): документация на русском языке, главная страница — `README.md`,
  отдельные страницы «История версий» (этот файл) и «Задание №1» (`pages/task1.md`).
- Модуль безопасного ввода `input.h` / `input.cpp`:
  - `readInt()` — читает целое число, отбрасывая некорректный ввод
    («abc», «12abc», «3.5», переполнение int);
  - `readIntInRange()` — читает число из заданного диапазона.
- Задание №1 (`task1.h` / `task1.cpp`), массив везде передаётся как ссылка
  на массив `int (&arr)[ARRAY_SIZE]`:
  - `fillArray()` — заполнение случайными числами (`<random>`) или с клавиатуры;
    способ заполнения задаётся параметром по умолчанию `FillMode::Random`;
  - `printArray()` — вывод через range-based for и `const auto&`;
  - `swapElements()` — обмен двух элементов по индексам с проверкой границ;
    сами элементы передаются по ссылке во вспомогательную `swapValues(int&, int&)`;
  - `multiplyByTwo()` — умножение на 2 через range-based for с `int& x`,
    с защитой от переполнения int;
  - `runTask1()` — интерактивное меню, из которого вызываются все функции.
- Главное меню программы (`main.cpp`) с выбором задания; задания 2–4 пока
  отмечены как «в разработке». Настройка консоли Windows на UTF-8.
- Страница документации `pages/task1.md`: условие, описание решения,
  объяснение используемых конструкций C++ и пример работы программы.

### Проверено

- Сборка `build.bat` (g++ 16.2.0) — без ошибок и предупреждений.
- `lab1.exe` запускается на компьютере без MinGW (зависит только от системных DLL Windows).
- Сценарии работы: заполнение с клавиатуры и случайными числами, вывод, обмен элементов,
  умножение на 2, повторное заполнение, возврат в главное меню, выход.
- Ошибки ввода: буквы, «12abc», «3.5», «99999999999», номера пунктов меню вне диапазона,
  индексы вне диапазона 0–9, одинаковые индексы, переполнение при умножении (2000000000 × 2),
  внезапный конец ввода (программа завершается с сообщением, без зацикливания).
- Doxygen 1.18.0 собирает документацию без предупреждений.

### Следующая версия (v0.2)

- Задание №2: динамический массив `new int[N]{}`, функция
  `process(int*& arr, int size)`, корректное освобождение памяти и обнуление указателя.
